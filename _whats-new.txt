03 - First API Call
-------------------

- ZABBIX API can be accessed from the JavaScript.
- ZABBIX API is based on Promises.
- ZABBIX API request format is similar to the PHP's version.
- ID type fields coming from the configuration are always arrays.
- The dashboard framework automates the views when using dynamic configuration.

https://www.zabbix.com/documentation/current/en/manual/api/reference/host/get
